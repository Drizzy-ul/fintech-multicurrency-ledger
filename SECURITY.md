# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please report it responsibly rather than opening a public issue.

### Disclosure Process:
1. **Email Details**: Send a description of the issue to **kelvinamarteywinston@gmail.com**.
2. **Include**:
   - Attack vector and reproduction steps or proof-of-concept (PoC).
   - Expected vs. actual behavior.
   - Any proposed mitigations or remediations.
3. **Response Timeline**:
   - Initial acknowledgement within **48 hours**.
   - Assessment and remediation timeline provided within **7 business days**.

We kindly ask that you keep details confidential until a patch has been merged. Thank you for helping keep our software secure!
